# 바탕화면 캘린더 (Windows)

## 설치
[Releases](../../releases) 에서 `DesktopCalendar-Setup-버전.exe` 를 내려받아 실행하면 바로 설치·실행됩니다.
설치판은 새 버전이 나오면 **"새로운 버전이 있습니다. 업데이트 하시겠습니까?"** 를 묻고, **예** 를 누르면 알아서 업데이트됩니다.

> 자동 업데이트는 이 저장소가 **공개(Public)** 일 때만 동작합니다.
> (저장소 Settings → General → 맨 아래 Danger Zone → Change visibility → Public)
> 코드에는 비밀번호 같은 비밀 정보가 들어 있지 않습니다.

## 사용법
- 처음 실행하면 달력과 메모가 **바탕화면 아이콘(폴더) 뒤**에 붙습니다. 이 상태에서는 클릭이 안 됩니다.
- 일정을 추가하려면 작업 표시줄 오른쪽 **달력 아이콘을 클릭**하거나 **Ctrl+Alt+C** → 편집 모드
- 다 쓰면 위쪽 **고정** 버튼(또는 다시 Ctrl+Alt+C)
- 여러 날 일정: 달력에서 날짜를 끌어서 선택하거나 시작일 ~ 종료일 입력
- 일정 이름 수정: 오른쪽 목록에서 이름을 더블클릭하거나 **수정**
- **메모** 버튼: 스티커 메모 창 보이기/숨기기
  - 아래 **+** 로 새 메모 시트, 시트 탭 **더블클릭**으로 제목, **오른쪽 클릭**으로 삭제
  - 위쪽 색 동그라미로 종이 색 변경, 위쪽 띠를 끌어서 이동
- **잠금** 버튼: 달력·메모 창 위치와 크기 고정
- ⚙ 설정: 색상, 투명도, 집·회사 연동, 업데이트 확인, 종료

## 집·회사 연동 설정 (처음 한 번)
연동은 무료 서비스인 Google **Firebase** 에 일정을 저장합니다. 아래를 한 번만 해 주세요.

1. https://console.firebase.google.com 에 구글 계정으로 로그인 → **프로젝트 추가** → 이름 아무거나(예: `my-calendar`) → 만들기
   (Google 애널리틱스는 꺼도 됩니다)
2. 왼쪽 메뉴 **빌드 → Authentication** → 시작하기 → **이메일/비밀번호** → 사용 설정 → 저장
3. 왼쪽 메뉴 **빌드 → Firestore Database** → 데이터베이스 만들기 → 위치 `asia-northeast3 (서울)` → **프로덕션 모드** → 만들기
4. Firestore 의 **규칙** 탭에 아래 내용을 붙여넣고 **게시**
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /calendars/{uid} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```
5. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래 "내 앱"에서 **</> (웹)** 아이콘 → 앱 이름 아무거나 → 등록
   → 화면에 나오는 `apiKey` 와 `projectId` 값을 `firebase-config.js` 에 넣습니다.
6. 새 버전이 빌드되면 앱의 ⚙ 설정 → **집·회사 연동** 에서 처음 한 번 **새로 가입**, 다른 컴퓨터에서는 같은 아이디로 **로그인**

비밀번호는 컴퓨터에 저장되지 않고, 로그인 상태만 기억합니다. 각자의 데이터는 보안 규칙 때문에 본인만 읽고 쓸 수 있습니다.

## 개발
Node.js 설치 후 `npm install && npm start` (또는 `시작하기.bat`)
