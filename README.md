# 바탕화면 캘린더 (Windows)

## 다운로드
[Releases](../../releases) 에서 `DesktopCalendar.zip` 을 내려받아 압축을 풀고 `바탕화면 캘린더.exe` 를 실행하세요.

## 사용법
- 처음 실행하면 캘린더가 **바탕화면 아이콘(폴더) 뒤**에 붙습니다. 이 상태에서는 클릭이 안 됩니다.
- 일정을 추가하려면 작업 표시줄 오른쪽 **달력 아이콘을 클릭**하거나 **Ctrl+Alt+C** → 편집 모드
- 다 쓰면 위쪽 **바탕화면에 고정** 버튼(또는 다시 Ctrl+Alt+C)
- 여러 날 일정: 달력에서 날짜를 끌어서 선택하거나 시작일 ~ 종료일 입력
- 🔒 잠금 버튼: 창 위치·크기 고정
- 일정 이름 수정: 오른쪽 목록에서 이름을 더블클릭하거나 **수정**
- 메모: 오른쪽 위 **메모** 탭 → 스티커 메모. 아래 **+** 로 새 메모 시트 추가, 시트 탭 더블클릭으로 제목, 오른쪽 클릭으로 삭제
- 날짜 클릭 → 오른쪽 사이드바에서 일정 내용·기간·시간·색상을 고르고 **일정 추가** (시간을 넣으면 그 시간에 알림)
- 위쪽 빈 곳을 끌어서 창 이동, 가장자리를 끌어서 크기 조절 (위치·크기는 기억됩니다)
- ⚙ 설정: 배경색·글자색·강조색, 글자 테두리, 투명도, 월요일 시작, 컴퓨터 켤 때 자동 실행, 종료

## 직접 실행 (개발용)
Node.js 설치 후 `시작하기.bat` 더블클릭, 또는 `npm install && npm start`
