# 바탕화면 캘린더 (Windows)

## 설치
[Releases](../../releases) 에서 `DesktopCalendar-Setup-버전.exe` 를 내려받아 실행하면 바로 설치·실행됩니다.
설치판은 새 버전이 나오면 **"새로운 버전이 있습니다. 업데이트 하시겠습니까?"** 를 묻고, **예** 를 누르면 알아서 업데이트됩니다.

> 자동 업데이트는 이 저장소가 **공개(Public)** 일 때만 동작합니다.

## 사용법
- 처음 실행하면 달력이 **바탕화면 아이콘(폴더) 뒤**에 붙습니다. 이 상태에서는 달력 클릭이 안 됩니다.
- 메모는 항상 달력보다 위에 있고, 언제든 옮기고 고칠 수 있습니다.
- 일정을 추가하려면 작업 표시줄 오른쪽 **달력 아이콘을 클릭**하거나 **Ctrl+Alt+C** → 편집 모드
- 다 쓰면 위쪽 **고정** 버튼(또는 다시 Ctrl+Alt+C)
- 여러 날 일정: 달력에서 날짜를 끌어서 선택하거나 시작일 ~ 종료일 입력
- 일정 옮기기: 달력의 일정 띠를 잡아서 다른 날짜에 놓기 (기간은 그대로)
- 일정 기간 바꾸기: 일정 띠의 왼쪽/오른쪽 끝을 끌기, 또는 오른쪽 목록의 📅 날짜 줄을 더블클릭해서 시작일·종료일·시간 수정
- 배경 투명도: 달력 위 오른쪽 ◐ 투명도 막대
- 검색: 달력 위 검색칸에 입력 → 오른쪽에 결과, 누르면 그 날짜로 이동
- 색 보기: 달력 위 색 동그라미를 누르면 그 색 일정만 (여러 색 선택 가능, **전체**로 해제)
- 일정 이름 수정: 오른쪽 목록의 일정이나 달력의 일정 띠를 **더블클릭**
- **메모** 버튼: 스티커 메모 창 보이기/숨기기
  - 아래 **+** 로 새 메모 시트, 시트 탭 **더블클릭**으로 제목, **오른쪽 클릭**으로 삭제
  - 위쪽 🎨 버튼으로 종이 색 변경, 위쪽 띠를 끌어서 이동
  - 위쪽 ☑ 버튼: 체크리스트 넣기 (네모를 누르면 체크, Enter 로 다음 항목, 빈 항목에서 Enter 로 끝내기, 제목 줄에 ✔ 완료/전체 표시)
  - 위쪽 ▦ 버튼: 표 넣기 (표 안에서 Tab 으로 다음 칸, 표 위 도구로 줄·칸 추가/삭제)
  - 위쪽 ◐ 버튼: 메모 투명도, 🔒 버튼: 메모 위치·크기 잠금 (달력 잠금과 별도)
- **바탕화면 캐릭터** (shimeji 처럼): 화면 아래를 걸어 다니고, 벽을 타고, 떨어지고, 앉아 쉬거나 잠을 잡니다.
  - 클릭: 깡충 뛰며 오늘 일정을 말풍선으로 알려줌 · 끌기: 잡아서 던지기 · 더블클릭: 달력 편집 모드
  - ⚙ 설정 → 바탕화면 캐릭터: 보이기/숨기기, 크기, **내 그림·zip 으로 바꾸기**(PNG·움직이는 GIF·JPG·WEBP, shimeji zip, 그림 여러 장 zip), 기본 캐릭터
- **뽀모도로** 버튼(⏱): 뽀모도로 타이머 창 열기/닫기
  - 집중 25분 → 짧은 휴식 5분, 집중 4번마다 긴 휴식 15분 (⚙ 에서 시간·자동 시작·소리 변경)
  - 무엇에 집중하는지 적어 두면 기록에 함께 남음, 끝나면 알림과 소리
  - 옛날 MP3 "Now Playing" 같은 화면: 타이머가 돌면 레코드판이 돌고, 진행 막대 왼쪽에 지난 시간·오른쪽에 남은 시간, 아래에 "○분 ○초 남았어요"
  - ≡ 에서 배경 설정 (기본 색 6가지, 두 색 직접 고르기)
  - ≡ → 표지 → 사진 추가: 가운데 레코드판이 그 사진(둥근 사각형 앨범 표지)으로 바뀌고 배경에도 흐리게 깔림, '레코드판'으로 원래대로
  - ≡ → 초기화: 오늘 · 이번 주 · 이번 달 · 기간 선택 · 전체 중 골라 그 기간의 뽀모도로 기록 지우기, 시간·배경 설정 처음 상태로
  - 📌 항상 위, 위쪽 띠를 끌어서 이동
- **🍅 뽀모도로 달력** (날짜 옆 버튼): 달력이 뽀모도로 기록만 보이게 바뀜
  - 날마다 🍅 횟수와 집중 시간, 많이 한 날일수록 진하게
  - 날짜를 누르면 그날 한 뽀모도로 목록(시간·집중한 일), 아래에 이번 달 합계
  - 다시 누르면(📅 일정 달력) 원래 달력으로
- **유튜브** 버튼: 작은 유튜브 창 열기/닫기 (로그인·마지막 영상·창 위치 기억)
  - 위쪽 띠의 ⠿⠿ (빈 곳)을 잡고 끌면 창 이동, 가장자리를 끌면 크기 조절
  - 위쪽 띠: 뒤로 · 홈 · 검색(또는 유튜브 주소 붙여넣기) · 📌 항상 위 · ─ 최소화 · ✕ 닫기, 띠를 더블클릭하면 재생/일시정지
  - **─ 최소화**를 누르면 화면 오른쪽 아래에 작은 **음악 바**(⏮ ⏯ ⏭ · 창 다시 열기 · 끄기)가 뜸. 음악 바는 끌어서 옮길 수 있고 위치를 기억
  - 작업 표시줄에는 따로 버튼이 생기지 않고, 대신 시계 옆 알림 영역에 유튜브 아이콘이 생김 (클릭: 창 보이기/숨기기, 오른쪽 클릭: ⏮ ⏯ ⏭ · 끄기)
  - ✕ 를 누르면 소리까지 완전히 꺼지고, 다음에 열면 유튜브 첫 화면부터
  - 구글 로그인이 막히지 않도록 일반 브라우저처럼 접속 (그래도 막히면 로그인 없이도 시청 가능)
  - 키보드의 미디어 키(재생/일시정지)도 그대로 동작
- **잠금** 버튼: 달력 창 위치와 크기 고정
- ⚙ 설정: 색상, 투명도, 업데이트 확인, 초기화(설정만 / 전체), 종료

## 개발
Node.js 설치 후 `npm install && npm start` (또는 `시작하기.bat`)
