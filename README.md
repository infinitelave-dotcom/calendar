# 바탕화면 캘린더 (Windows)

1. https://nodejs.org 에서 **LTS** 버전을 설치합니다 (다음 → 다음 → 설치).
2. 이 폴더의 `시작하기.bat` 을 더블클릭합니다. 처음에는 필요한 파일을 내려받느라 몇 분 걸립니다.
3. 바탕화면에 캘린더가 나타납니다.

## 사용법
- 날짜 클릭 → 아래에서 일정 입력 후 Enter (시간을 넣으면 그 시간에 알림)
- 상단 빈 곳을 끌어서 창 이동, 가장자리를 끌어서 크기 조절 (위치·크기는 기억됩니다)
- ⚙ 버튼: 투명도, 월요일 시작, 컴퓨터 켤 때 자동 실행, 종료

## 설치 파일(.exe) 만들기 (선택)
터미널에서 `npm run build` → `dist` 폴더에 실행 파일이 생깁니다.
